# ศูนย์จัดการการเชื่อมต่อ

ผู้ดูแลเปิด `/settings` เพื่อดูสถานะการตั้งค่าและกดตรวจ MySQL, LINE และ Facebook ทีละรายการ ผลเป็นการตรวจ ณ เวลาที่กด ไม่ใช่ monitoring อัตโนมัติ ไม่มีประวัติถาวรหรือการแจ้งทีมภายนอก สถานะว่ามีค่าไม่ยืนยันว่าค่านั้นถูกต้อง ผลตรวจไม่แสดง token, URL ฐานข้อมูล หรือข้อความ error จากผู้ให้บริการ

MySQL ใช้ `DATABASE_URL` ที่ตั้งบนเซิร์ฟเวอร์เท่านั้น โดยเชื่อมต่อและสั่ง `SELECT 1` พร้อม timeout 8 วินาที ไม่สร้างตาราง ไม่อ่านข้อมูลลูกค้าและไม่แก้ schema ควรใช้บัญชี MySQL สิทธิ์จำกัดสำหรับการสำรวจ ตรวจการเข้ารหัส TLS และการเข้าถึงเครือข่ายตามโครงสร้าง hosting จริง ค่า URL และ secrets ต้องเก็บในช่องทางปลอดภัย ห้ามส่งผ่านแชทหรือ commit เข้าระบบ source control

**ผล SELECT 1 ผ่านไม่ได้หมายความว่า CRM ใช้ MySQL:** แอปยังใช้ JSON เดโม บัญชีจริงยังไม่เชื่อม และต้องตรวจ schema ของฐานเดิมก่อนพัฒนา adapter และทดสอบกับสำเนาแยก โดยไม่เปลี่ยน schema เดิม ผล LINE/Facebook ไม่ยืนยัน webhook หรือการส่งจริง หน้านี้ไม่รองรับการบันทึก credentials และยังไม่พร้อมใช้กับข้อมูลลูกค้า production
